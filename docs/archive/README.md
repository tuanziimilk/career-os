# 已完成事项的记录

> **这里的文档不要照着做。** 它们记的是某件事**当时**怎么做的、为什么那么决定、
> 以及过程中踩到了什么 —— 事情已经做完了。

和 `docs/` 下那几份的区别：

| 位置 | 性质 | 读它的理由 |
|---|---|---|
| `docs/FEATURES.md` | 资产清册 | **动手前查**，避免重做已经存在的功能 |
| `docs/PRD.md` · `docs/ROADMAP.md` | 常驻 | 要做什么、什么时候才值得做 |
| `docs/待修-*.md` | **还活着的待办** | 里面的条目还没做完 |
| `docs/archive/` | 一次性记录 | 想知道"当初为什么这么定"时才翻 |

分开放的理由很具体：带日期的一次性文档会越积越多，混在常驻文档里，
读的人分不清**「这份还要照着做」**和**「这份是当时的记录」**——
而照着一份已经过期的操作文档动手，比没有文档更糟。

⚠️ 归档不等于作废。里面的**判断依据**通常仍然成立（比如迁移那份记着
「一道会优雅降级的闸门，在迁移里会静默失效」），只是**操作步骤**已经执行过了。
